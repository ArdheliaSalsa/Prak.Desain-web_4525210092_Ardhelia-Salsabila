# Profil Mahasiswa - HTML Sederhana

Proyek ini adalah halaman web statis sederhana yang berisi halaman profil mahasiswa. Proyek ini dibuat sebagai bentuk latihan dasar pemahamanan struktur HTML, pemformatan teks, serta penggunaan karakter khusus (HTML entities).

---

## 🚀 Fitur & Komponen Kode

Halaman web ini mengimplementasikan beberapa elemen dasar HTML5:

* **Struktur Dokumen**: Menggunakan deklarasi `<!DOCTYPE html>` dan atribut bahasa `lang="id"`.
* **Hierarki Judul**: Penggunaan tag `<h1>`, `<h2>`, dan `<h3>` untuk penataan struktur judul dan sub-bagian.
* **Pemformatan Teks**:
  * Teks tebal menggunakan `<strong>` dan `<b>`.
  * Teks miring menggunakan `<em>`.
  * Teks bergaris bawah menggunakan `<u>`.
  * Pemisah baris menggunakan `<br>`.
* **HTML Entities**: Penggunaan karakter khusus seperti `&lt;` (`<`), `&gt;` (`>`), dan `&copy;` (`©`).

## 💻 Cara Menjalankan Proyek

1. Unduh atau salin kode ke dalam sebuah file di komputer Anda.
2. Simpan file tersebut dengan nama **`index.html`**.
3. Klik dua kali pada file `index.html` atau buka menggunakan peramban web (*web browser*) seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge.
